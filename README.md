# 🧹 Smart File Organizer CLI

A lightning-fast, zero-dependency Python CLI tool that instantly cleans up and organizes messy directories (like your Downloads or Desktop folder) into neat categories.

---

## ✨ Features
- **Zero Dependencies:** Uses only Python standard library (`pathlib`, `shutil`, `argparse`).
- **Smart Categorization:** Automatically sorts files into `Images`, `Documents`, `Code`, `Archives`, `Media`, `Executables`, and `Others`.
- **Safe Mode:** Supports `--dry-run` to preview changes before moving any files.
- **Collision Safe:** Handles file name conflicts automatically (renames duplicates safely).

---

## 🚀 Quick Start

1. Clone or download `file_organizer.py`.
2. Run it in any directory:

```bash
python file_organizer.py /path/to/messy/folder
```

Or run it in the current directory:
```bash
python file_organizer.py
```

Preview changes without moving files:
```bash
python file_organizer.py --dry-run
```
